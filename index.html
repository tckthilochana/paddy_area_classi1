How This System Supports Agricultural Officers

01

Spatial Paddy Identification

Visualise predicted paddy-field locations from satellite observations instead of relying only on tabular agricultural statistics.

02

GN/DS-Level Area Estimation

Automatically summarise predicted paddy extent by GN Division and DS Division.

03

Field Verification Support

Highlight areas where satellite-based predictions differ from available agricultural records, helping officers identify locations for further verification.

04

Seasonal Monitoring

Compare paddy extent across Yala and Maha seasons and across different years when suitable satellite imagery is available.

05

Evidence-Based Planning

Provide spatial information that can support agricultural monitoring, planning and resource allocation.

How the Machine Learning Model Works

View model workflow
Satellite imagery is collected for the selected season.
↓
Sentinel-2 provides optical information.
↓
Sentinel-1 provides radar information.
↓
Vegetation, moisture and radar features are derived.
↓
A 25-band temporal feature dataset is created.
↓
Reference paddy and non-paddy areas are used for model training.
↓
A machine-learning classifier learns the relationship between satellite features and paddy/non-paddy classes.
↓
The trained model predicts paddy probability for pixels across the study area.
↓
Predicted pixels are converted into spatial paddy-area estimates.

Multi-Year Monitoring

The proposed framework is designed to support analysis of historical and subsequent seasons when suitable Sentinel-1/Sentinel-2 imagery and reference information are available.

2016 → 2017 → 2018 → ... → 2026 → 2027

Model performance for new years should be evaluated and, where necessary, the model should be updated using new validated reference data.

About Research

Counterfactual Analysis for Climate-Resilient Paddy Farming using Explainable Artificial Intelligence

  • Study area: Anuradhapura District, Sri Lanka
  • Current research stage: Paddy Area Classification – Prototype
  • Research technologies: Google Earth Engine, Sentinel-1, Sentinel-2, Machine Learning, Explainable AI, GIS, Python

Current prototype uses demonstration data. Final predictions will be generated only after validated reference data and model evaluation are completed.
